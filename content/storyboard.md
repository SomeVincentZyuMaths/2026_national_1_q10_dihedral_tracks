# 十幕分镜（2 分 02 秒）

| 场景 | 时间 | 画面问题 | 定格讲解 |
|---|---|---|---|
| 00 原题 | 0–10 秒 | 先读题，不公布答案 | 先读题，注意二面角的顶点和 ∠CAD 的顶点是否相同。 |
| 01 建系 | 10–21 秒 | 60° 究竟是哪两条线的夹角？ | 把 O₂D 平移到 O₁D′，方向不变。金色角弧才是二面角的平面角。 |
| 02 B · 投影 | 21–33 秒 | 先求截面上的 CD′ | 在三角形 CO₁D′ 中用余弦定理。求出的是投影 CD′ 的长度。 |
| 03 B · 下界 | 33–48 秒 | 把空间距离拆成两条直角边 | 让 O₂ 滑到 O₁：轴向距离变为零，D 与 D′ 重合。下界可以取到，B 正确。 |
| 04 C · 分量 | 48–63 秒 | 为什么 AB⊥CD 就能让两点共截面？ | y_B 非零，所以 y_D=y_C。两个垂足合为 O，C、D、O 同在垂直于 y 轴的截面内。 |
| 05 C · 直角 | 63–73 秒 | 截面里还有哪两条线垂直？ | 由勾股定理的逆定理，直角在 D 点。因此 CD 垂直于 OD。 |
| 06 C · 判定 | 73–85 秒 | 平面内找两条相交直线 | CD 垂直于 AB 是前提，垂直于 OD 是上一幕所得。由线面垂直判定，C 正确。 |
| 07 A · 反例 | 85–101 秒 | 同一个 60° 二面角，能否得到 45° 的 ∠CAD？ | AD=CD=√3，而且 CD⊥AD。三角形 ADC 是等腰直角三角形，A 点的角只有 45°。 |
| 08 D · 反例 | 101–114 秒 | 把整个截面移到 A，前提成立了 | 此时 AC、AD 就是夹角 60° 的两条半径。点积等于 1，不是 0，所以 AC 不垂直于 AD。 |
| 09 回看 | 114–122 秒 | 四个选项，各留一条理由 | A：45° 反例；B：投影给出下界 √3；C：垂直于平面内两条相交直线；D：截面过 A 时夹角为 60°。 |

00 ↔ 01 的题面可逆淡入淡出；01 起题干和四个选项常驻。02 沿轴观察投影；03 回到空间画直角；05 沿轴看截面；07、08 让两个圆心同步移动。
